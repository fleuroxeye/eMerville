# eMerville
A student-developed HCI project focused on user-centered web design, featuring online barangay document requests, real-time tracking, and digital blotter reporting using HTML, CSS, and JavaScript.
## Overview

eMerville is a web-based Barangay Management System developed using HTML, CSS, and JavaScript. The project aims to improve the accessibility and efficiency of barangay services through an intuitive and visually appealing interface.

## Features

- Online Barangay Document Requests
- Real-Time Request Tracking
- Digital Blotter Report Submission
- Responsive User Interface
- User-Centered Design

## Technologies Used

- HTML
- CSS
- JavaScript

## Academic Information

This project was developed as a requirement for the Human-Computer Interaction (HCI) course, emphasizing usability, accessibility, visual hierarchy, and user experience design principles.
